# Backtest Statistical Analysis Skill

## Instructions

バックテストの結果が報告された際、または最適化のプロセスにおいて、以下の統計的プロセスを自律的に実行すること。

### 1. 探索的データ解析 (EDA)
- **リターンの分布**: トレードごとのリターン分布（ヒストグラム）を確認し、正規分布からどれだけ乖離しているか（歪度・尖度）を評価してください。
- **アウトライヤーの特定**: 少数（1〜2回）の巨大な利益が全体のパフォーマンスを底上げしていないか確認してください。

### 2. 主要なリスク調整後パフォーマンス指標
- **Sharpe / Sortino Ratio**: リスクに対するリターンの効率を評価します。特に下落リスクのみを考慮した Sortino Ratio を重視してください。
- **Calmar Ratio**: 年率リターンと最大ドローダウン (MDD) の比率を確認し、回復の効率を評価してください。
- **Profit Factor / Expectance**: システムの「期待値」を算出し、コストを考慮しても利益が残るかを確認してください。

### 3. プロジェクト固有の正規化 (Little's Law)
- **Little's Law 適用**: 銘柄の平均保有期間 $L$ と回転率から、単純な加算ではない「ポートフォリオ等価パフォーマンス」を算出してください。
- **等価 MDD**: 複数銘柄の同時保有状況を考慮し、現実的に想定される最大下落幅を推定してください。

### 4. 統計的有意性の検証 (Robustness)
- **Monte Carlo Simulation**: トレード順序をランダムに入れ替え、MDD や破綻確率の変化をシミュレーションし、結果が運に左右されていないかを確認してください。
- **有意差検定 (t-test)**: 平均リターンが 0 であるという帰無仮説を棄却できるか（p-value < 0.05）を確認してください。
- **Bootstrap法**: データセットから重複を許して再抽出を行い、指標の信頼区間（95%など）を算出してください。

### 5. カーブフィッティングの警告
- 試行したパラメータの数に対して、十分なサンプル（トレード数）があるか確認してください。
- **Walk-forward Analysis**: 学習期間とテスト期間をずらし、未知のデータ期間でもパフォーマンスが維持されているかを評価してください。

### 6. RRG指標との整合性
- バックテストに `rs_ratio` や `rs_momentum` が含まれる場合、それらが「0センター」で正しく処理されているか、偏りがないかをチェックしてください。
