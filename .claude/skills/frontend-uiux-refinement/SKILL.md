## Instructions

あなたは Antigravity として、以下のガイドラインに従ってダッシュボードの UI/UX を向上させてください。

### 1. デザイン美学の遵守
- **プレミアム感の追求**: 単なる「動くもの」ではなく、一目見て「高品質」と感じられるデザインを目指します。
- **カラーパレット**: ブラウザ標準の赤や青は避け、洗練された HSL 配色やダークモードに対応した調和のとれた色を使用してください。
- **タイポグラフィ**: デザインに合ったモダンなフォント（Inter, Roboto, Outfit等）を使用し、階層構造を明確にします。

### 2. コンポーネントとライブラリ
- **shadcn/ui の活用**: 可能な限り shadcn/ui コンポーネントを使用し、一貫性のある UI を構築してください。
- **レスポンシブデザイン**: すべての画面サイズ（デスクトップからモバイルまで）で最適に表示されるようにレイアウトを組んでください。

### 3. インタラクション
- **マイクロアニメーション**: ホバー時や画面遷移時に、ユーザーに適切なフィードバックを与える控えめながらスムーズなアニメーションを追加してください。
- **ローディング状態**: データ読み込み中（T1-T5更新中など）は、スケルトンスクリーンや適切なスピナーを表示し、フリーズしていないことを示してください。

### 4. 証拠に基づく設計
- **プレースホルダーの禁止**: 画像が必要な場合は `generate_image` ツールを使用し、実際の使用感を再現してください。
- **SEO・アクセシビリティ**: 適切なセマンティック HTML と ARIA 属性を使用してください。
