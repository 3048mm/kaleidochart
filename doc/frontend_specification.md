# フロントエンド仕様書 (Frontend Specification)

## 1. 概要
本プロジェクトのフロントエンド（`frontend/`）は、**Vite + React (TypeScript)** を用いたシングルページアプリケーション（SPA）です。
バックエンドが集計・算出済みのデータをREST API経由で取得し、高速かつ視覚的なチャートや一覧表として表示します。
ダッシュボードによるシステム全体の俯瞰、個別の株価チャートの分析、および独自指標による強力なスクリーナー機能を提供します。

## 2. 技術スタック・構成
*   **フレームワーク**: React 18, TypeScript
*   **ビルド・開発サーバー**: Vite (デフォルトポート: 5173 または 51740等)
*   **ルーティング**: React Router DOM (複数画面のSPA遷移)
*   **グラフィック・チャート**: `lightweight-charts` (軽量かつ高性能な TradingView 互換チャート)
*   **スタイリング**: CSS Modules または TailwindCSS 相当のユーティリティ（実態: モジュラーCSSベース）
*   **バックエンド通信**: Axios/Fetch による `http://localhost:8001/api/...` との通信。ViteのProxy設定で `/api` を自動転送。

## 3. 主要画面と機能

### 3.1 ダッシュボード画面 (`/` - `DashboardPage`)
相場全体の状況を一目で把握するためのホームページ。
*   **ヘッダーパネル**:
    *   **マーケットフェーズ (Market Phase)**: 過去のS&P500の動向から、現在の市場が強気（BULL）か調整（CORRECTION）か等を表示。
    *   **Market Trend Score**: 0-100の定量スコア。
    *   **Distribution Days**: 上値抑えや売り圧力の強さを示す指標カウント。
*   **情報タブ (Tabs)**:
    *   **Indicators**: 
        - **Market Trend Score History**: 直近100日の定量スコア推移グラフ。
        - **SPY Detailed Panel**: SPYの主要な乖離率や直近トレンド。
        - **Leading Indicators**: TLT, VIX, USOなど主要な先行指標の一覧。
    *   **Markets**: `category='市場'` のインデックス銘柄一覧（SPY等）。
    *   **Sectors & Themes**: `category='セクタ'` や `category='テーマ'`（独自作成の仮想指数含む）の銘柄。`rs_ratio_21` 値を元に Top / Weak（上位/下位）でソート表示。
        - **テーマリンク**: 各行をクリックすることで、その詳細（所属銘柄の一覧）を表示する「グループ詳細画面」へ遷移。

*   **表内要素（共通）**:
    *   **スパークライン (Sparkline)**: 各銘柄の直近のトレンドや相対ランク推移をSVGミニチャートで可視化。中央に水平の基準線（破線）を表示し、レンジの中央より上か下かを判別可能にしている。
    *   **カラーラベル**: 日次の変動率（%1D, %1W）に応じ、上昇(Good/緑)、下落(Bad/赤)でわかりやすく色分け。
    *   **RSスコア列**: 14日・21日・63日 スパンでの市場内での強さ(0〜100)。

### 3.2 グループ詳細画面 (`/group/:ticker` - `GroupPage`)
セクタまたはテーマの構成銘柄を深掘りするためのドリルダウン画面。
*   **ETF詳細パネル (`EtfFeaturePanel`)**: 該当セクタ/テーマETF自体のパフォーマンス（1D, 1W, 1M, 1Y）と 6ヶ月チャートを表示。
*   **構成要素テーブル (`SummaryTable`)**: 
    - **セクタ詳細時**: 当該セクタに属する「テーマ ETF」を RS スコア順に一覧表示。
    - **テーマ詳細時**: 当該テーマを構成する「個別銘柄」を RS スコア順に一覧表示。

### 3.3 個別チャート画面 (`/chart/{ticker}` - `ChartPage`)
特定のティッカーに対して詳細なテクニカル分析を行うページ。ダッシュボードから銘柄名をクリックすると遷移する。
*   **ヘッダー情報**:
    *   **所属テーマタグ**: 銘柄名の横に、バックエンドから提供される関連テーマ（ETFやセクター、タグ等）を pill 型のタグとして表示。各タグはリンクになっており、クリックすることで該当テーマのチャートへ遷移可能。
    *   **★ ウォッチリストボタン**: ヘッダー部（銘柄名の近く）に★トグルボタンを配置。未登録時は☆（白抜き）、登録済みは★（塗りつぶし）。クリックで登録/解除をトグル。登録時の entry_date は DB 上の最新営業日。
*   **チャートビュー (Chart View)**:
    *   **価格データ (Candlestick)**: OHLCベースのローソク足。
    *   **テクニカル指標 (Overlays)**: 上部のトグルボタンで動的に表示/非表示を切り替え可能。
        *   **SMA (単純移動平均)**: 21, 50, 63, 150, 200 日線
        *   **EMA (指数平滑移動平均)**: 5, 21, 50, 63, 200 日線
    *   **出来高 (Volume)**: 下部のヒストグラムペイン。
    *   **データ履歴テーブル (`SymbolDataTable`)**: ページ下部に、OHLC、出来高、**時価総額（Market Cap）**、および各種テクニカル指標の数値を時系列で一覧表示。ミネルヴィニの VCP 判定などに必要なボラティリティ収縮（VCR）などもここで確認可能。
*   **各種マーカー表示**:
        *   **TD9 (Sequential)**: 1〜9のカウントをローソク足の上(下落時)・下(上昇時)に数で明示。
        *   **ATR乖離マーカー**: 50日SMAからATRの一定倍率以上乖離した場合に丸型マーカーを表示。乖離率を警告として可視化。
    *   **比較機能 (Comparison)**: 他のティッカー（例: `QQQ`）を入力して同じチャート上に相対推移ライン（左Y軸）をオーバーレイ。

    *   **RSビュー (Relative Rotation Graph & RS Line Chart)**:
    *   「RS View」タブに切り替えると、JS Custom RRG（相対回転グラフ）と、TradingViewベースのRSラインチャートが表示される。
    *   **RSラインチャート (上部)**:
        *   `relative_strength_spy` をメインシリーズとして表示。
        *   `rs_ema_14`, `rs_ema_21`, `rs_ema_63` をオーバーレイ表示（デフォルトON）。
        *   市場に対する相対的な強さの時系列推移を可視化。
    *   **RRGチャート (下部)**:
        *   X軸に `RS-Ratio`、Y軸に `RS-Momentum` を取った散布図の軌跡（Trail）を描画。Quadrant（象限）により、Leading(先導), Weakening(弱体化), Lagging(出遅れ), Improving(改善) を視覚化。
    *   **ミニマップ**: RSスコア郡の%Rankの直近30日の時系列推移を左側サイドパネルに表示。

### 3.4 スクリーナーダッシュボード画面 (`/screener` - `ScreenerPage`)
データベースに蓄積された全銘柄に対して、TOMLファイル（`screener_presets.toml`）で定義された独自の検索条件（プリセット）を適用した結果のサマリーを一覧表示する画面。
*   **日付ナビゲーション**: 画面上部で基準日（Base Date）を変更でき、過去の時点でのスクリーナー結果を再現できる。
*   **Rise / Fall タブ**: 買い目線の条件（Rise）と警戒・売り目線の条件（Fall）をタブで切り替え。
*   **プリセットパネル群**: 各条件に該当した銘柄のトップ8件をミニパネルで表示。パネルタイトルをクリックすると、詳細な結果と追加フィルタリングが可能な「スクリーナー結果画面（ScreenerResultPage）」へ遷移。

### 3.5 スクリーナー結果画面 (`/screener/result/:presetId` - `ScreenerResultPage`)
特定のプリセットから遷移、もしくはカスタムでフィルタリングを行うための詳細画面。
*   **カスタムフィルタ（左側サイドバー）**: 各種テクニカル・モメンタムフィルタを動的に設定（APIからメタデータを取得して動的構築）。
    *   **Price & Trend**: 移動平均距離、各種騰落率、Trend Template適合など。
    *   **Volume & Volatility**: ADR%, 出来高急増倍率等。
    *   **Fundamentals**: **時価総額（Market Cap）** の範囲指定。
    *   **Momentum & RS**: RS Rank値の範囲指定。
    *   **Special Conditions (特殊条件)**: RRG象限への突入検知（`RRG Leading In`, `RRG Lagging In`, `RRG Improving In`）、RS21とRS63のクロスオーバーフラグ（等、単純な数値比較では表現できない特殊な真偽値フィルタ）。
*   **銘柄テーブル（右側メイン表示）**:
    *   条件に合致した全ての銘柄がリアルタイムに表示される。
    *   表の各カラム（`%1D`, `Vol SG`, `RS21`, etc...）をクリックすることでソートが可能。
    *   ティッカー名から該当銘柄の個別チャート画面（ChartPage）へジャンプ。
    *   **★ ウォッチリストボタン**: 各行の左端に★ボタンを配置。クリックでウォッチリストへの追加/解除を即座に行う。entry_date は画面で選択中の基準日が使用される。

### 3.6 ウォッチリスト画面 (`/watchlist` - `WatchlistPage`)
ユーザーが注目銘柄として登録した銘柄のパフォーマンスを一覧管理する専用画面。
*   **タブ切替**: 「Active（登録中）」と「Removed（解除済み）」の2タブ。
*   **Active タブ**:
    *   テーブル列: 指定日 | Ticker | Name | 指定日終値 | 最新終値 | EMA21 | %Gain | Max%Gain | Min%Gain | ADR% | SMA50/ATR% | RS ミニグラフ
    *   指定日はインライン編集可能（日付入力 → PUT API で更新）
    *   ★ボタンで解除（DELETE API）
    *   行クリックで `/chart/{ticker}` へ遷移
    *   デフォルトソート: 登録日（entry_date）降順
*   **Removed タブ**:
    *   テーブル列: 指定日 | Ticker | Name | 登録時終値 | 解除時終値 | 登録～解除 %Gain | 解除日
    *   「一括クリア」ボタン → 確認ダイアログ → 解除済みレコードを全件物理削除
    *   行クリックで `/chart/{ticker}` へ遷移

## 4. UI 共通コンポーネント
*   **Sparkline (components/Sparkline.tsx)**
    *   ダッシュボード一覧で価格推移やスコア推移を示すインラインのSVGグラフ。
*   **EtfFeaturePanel (components/EtfFeaturePanel.tsx)**
    *   ETFの主要KPIS（騰落率、SMA乖離率）とトレンドチャートを統合したパネル。
*   **SummaryTable (components/SummaryTable.tsx)**
    *   銘柄リスト（名前、価格、騰落率、スパークライン、RSランク等）を表示する標準化されたテーブル。
*   **Navigation Header**
    *   Dashboard, Screener, Watchlist などの画面切り替えルーターリンクを常に上部に配置。
