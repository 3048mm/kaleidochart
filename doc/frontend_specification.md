# フロントエンド仕様書 (Frontend Specification)

## 1. 概要
本プロジェクトのフロントエンド（`frontend/`）は、**Vite + React (TypeScript)** を用いたシングルページアプリケーション（SPA）です。
バックエンドが集計・算出済みのデータをREST API経由で取得し、高速かつ視覚的なチャートや一覧表として表示します。
ダッシュボードによるシステム全体の俯瞰、個別の株価チャートの分析、および独自指標による強力なスクリーナー機能を提供します。

## 2. 技術スタック・構成
*   **フレームワーク**: React 18, TypeScript
*   **ビルド・開発サーバー**: Vite (デフォルトポート: 5173 または 51740等)
*   **ルーティング**: React Router DOM (複数画面のSPA遷移)
*   **グラフィック・チャート**: `lightweight-charts` (軽量かつ高性能な TradingView 互換チャート)
*   **スタイリング**: CSS Modules または TailwindCSS 相当のユーティリティ（実態: モジュラーCSSベース）
*   **バックエンド通信**: Axios/Fetch による `http://localhost:8000/api/...` との通信。ViteのProxy設定で `/api` を自動転送。

## 2.1 共通レイアウトとサイドバー (Common Layout & Sidebar)
アプリケーション全体を包むレイアウトとして、レスポンシブなヘッダーおよび折りたたみ可能なサイドバー（`app-sidebar`）が実装されています。

*   **ヘッダー (`app-header`)**:
    *   画面幅が狭いモバイル環境などでは、左端のハンバーガーボタンでサイドバーの表示/非表示を切り替えられます。
    *   現在の接続中データベース名を表示する警告バッジ（本番以外接続時）や、各主要画面へのルーターリンク、ライブステータスが表示されます。
*   **サイドバー (`app-sidebar`)**:
    *   **アコーディオンツリー構造**: 膨大なテーマやセクターリストに対処するため、カテゴリー（市場、指標、セクタ、テーマ、個別）ごとの開閉式アコーディオンを採用しています。
    *   **デフォルト表示**: 初期状態では画面のすっきりさと利便性を両立するため、**「個別」カテゴリーのみを展開**し、その他の「市場」「指標」「セクタ」「テーマ」は折りたたまれた状態で表示されます。
    *   **検索連動型自動展開**: 検索入力欄（クリア用の `✕` ボタン付き）に1文字でも入力すると、**すべてのカテゴリーが強制的に自動展開**され、閉じているアコーディオンの内部にあるテーマ等も一括して検索ヒットさせることができます。検索をクリアすると、元の「個別のみ展開」の状態に戻ります。
    *   **テーマ名のデリミタ分割表示**: テーマの命名規則 `{ThemeGroup}::{Theme}` （例: `サイバーセキュリティ::クラウド・セキュリティ`）に基づき、フロントエンド側で自動的に `::` をデリミタとして検知し、上段に `ThemeGroup` （小さめの文字）、下段に `Theme` （メインの太字）の2段構成で美しく描画します。

## 3. 主要画面と機能

### 3.1 ダッシュボード画面 (`/` - `DashboardPage`)
相場全体の状況を一目で把握するためのホームページ。
*   **ヘッダーパネル**:
    *   **マーケットフェーズ (Market Phase)**: 過去のS&P500の動向から、現在の市場が強気（BULL）か調整（CORRECTION）か等を表示。
    *   **Market Trend Score**: 0-100の定量スコア。
    *   **Distribution Days**: 上値抑えや売り圧力の強さを示す指標カウント。
*   **情報タブ (Tabs)**:
    *   **Indicators**: 
        - **Market Trend Score History**: 直近100日の定量スコア推移グラフ。
        - **SPY Detailed Panel**: SPYの主要な乖離率や直近トレンド。
        - **Leading Indicators**: TLT, VIX, USOなど主要な先行指標の一覧。
    *   **Markets**: `category='市場'` のインデックス銘柄一覧（SPY等）。
    *   **Sectors & Themes**: `category='セクタ'` や `category='テーマ'`（独自作成の仮想指数含む）の銘柄。`rs_ratio_e21` を元に Top / Weak（上位/下位）でソート表示。
        - **テーマリンク**: 各行をクリックすることで、その詳細（所属銘柄の一覧）を表示する「グループ詳細画面」へ遷移。

*   **表内要素（共通）**:
    *   **スパークライン (Sparkline)**: 各銘柄の直近のトレンドや相対ランク推移をSVGミニチャートで可視化。中央に水平の基準線（破線）を表示し、レンジの中央より上か下かを判別可能にしている。
    *   **カラーラベル**: 日次の変動率（1D%, 1W%）に応じ、上昇(Good/緑)、下落(Bad/赤)でわかりやすく色分け。
    *   **RSスコア列**: 14日・21日・63日 スパンでの市場内での強さ(0〜100)。

### 3.2 グループ詳細画面 (`/group/:ticker` - `GroupPage`)
セクタまたはテーマの構成銘柄を深掘りするためのドリルダウン画面。
*   **ETF詳細パネル (`EtfFeaturePanel`)**: 該当セクタ/テーマETF自体のパフォーマンス（1D%, 1W%, 1M%, 1Y%）と 6ヶ月チャートを表示。
*   **構成要素テーブル (`SummaryTable`)**: 
    - **セクタ詳細時**: 当該セクタに属する「テーマ ETF」を RS スコア順に一覧表示。
    - **テーマ詳細時**: 当該テーマを構成する「個別銘柄」を RS スコア順に一覧表示。

### 3.3 個別チャート画面 (`/chart/{ticker}` - `ChartPage`)
特定のティッカーに対して詳細なテクニカル分析を行うページ。ダッシュボードから銘柄名をクリックすると遷移する。
*   **ヘッダー情報**:
    *   **所属テーマタグ**: 銘柄名の横に、バックエンドから提供される関連テーマ（ETFやセクター、タグ等）を pill 型のタグとして表示。各タグはリンクになっており、クリックすることで該当テーマのチャートへ遷移可能。
    *   **★ ウォッチリストボタン**: ヘッダー部（銘柄名の近く）に★トグルボタンを配置。未登録時は☆（白抜き）、登録済みは★（塗りつぶし）。クリックで登録/解除をトグル。登録時の entry_date は DB 上の最新営業日。
*   **チャートビュー (Chart View)**:
    *   **価格データ (Candlestick)**: OHLCベースのローソク足。
    *   **データソースの切り替え（Full Range）**:
        - 表示切り替えタブ（Chart View, RS View 等）の右端に「Full Range」トグルボタンを配置。
        - 通常は SQLite データベース（直近2年分の一時キャッシュ）からデータを取得するが、オンにすることで API の `?full_range=true` をトリガーし、Parquet Masterキャッシュに保存されている全期間の履歴データ（2019年以前を含む）に切り替えてグラフを描画する。ボタン上には読み込み元を補足するツールチップが表示される。
    *   **テクニカル指標 (Overlays)**: 上部のトグルボタンで動的に表示/非表示を切り替え可能。
        *   **SMA (単純移動平均)**: 21, 50, 63, 150, 200 日線
        *   **EMA (指数平滑移動平均)**: 5, 21, 50, 63, 200 日線
    *   **構造ピボット (LL-HL)**: 「構造」トグルで表示。押し目構造（安値切り上げ）と
        そのブレイクアウト水準を描画する。ON のときだけ
        `GET /api/chart/{id}/structure_pivot` を取得する（既定は OFF）。
        *   **現在の構造**: LL→HL を結ぶ破線 ＋ ピボット水準の実線 ＋ LL / HL のマーカー。
        *   **過去の構造**: ピボット水準（＝過去の抵抗線）だけを点線で最大30本。
            TradingView 版も勝者が交代した時点で構造線を消し、ピボット線だけを履歴へ送る。
        *   線分とマーカーの組み立ては `src/api/structurePivot.ts` の純関数
            （`buildStructureSegments` / `buildStructureMarkers`）。**両端の日付が
            ローソク足のデータに存在しない線分は捨てる** — lightweight-charts は
            データに無い時刻を渡すと描画が壊れるため。
    *   **Zone Break (SSL/BSL/FVG)**: 「ZoneBreak」トグルで表示。ON のときだけ
        `GET /api/chart/{id}/zone_break` を取得する（**既定は OFF** — バックテストで
        単体のエッジが確認できなかったため。経緯: `doc/completed/zone_break_plan.md` §6）。
        *   **SSL/BSL の現在区間**: 色分けした実線（SSL=緑寄り、BSL=赤寄り）。
        *   **FVG ボックス**: lightweight-charts v4 に矩形描画の標準APIが無いため、
            上端・下端の2本の線分（輪郭のみ）で表現。無効化済みは薄いグレーの点線。
        *   線分の組み立ては `src/api/zoneBreak.ts` の純関数
            （`buildZoneBreakLevelSegments` / `buildZoneBreakFvgSegments`）。
            構造ピボットと同じく、ローソク足のデータに無い日付の線分は捨てる。
    *   **出来高 (Volume)**: 下部のヒストグラムペイン。
    *   **データ履歴テーブル (`SymbolDataTable`)**: ページ下部に、OHLC、出来高、**時価総額（Market Cap）**、および各種テクニカル指標の数値を時系列で一覧表示。ミネルヴィニの VCP 判定などに必要なボラティリティ収縮（VCR）などもここで確認可能。
*   **各種マーカー表示**:
        *   **TD9 (Sequential)**: 1〜9のカウントをローソク足の上(下落時)・下(上昇時)に数で明示。
        *   **ATR乖離マーカー**: 50日SMAからATRの一定倍率以上乖離した場合に丸型マーカーを表示。乖離率を警告として可視化。
    *   **比較機能 (Comparison)**: 他のティッカー（例: `QQQ`）を入力して同じチャート上に相対推移ライン（左Y軸）をオーバーレイ。

    *   **RSビュー (Relative Rotation Graph & RS Line Chart)**:
    *   「RS View」タブに切り替えると、JS Custom RRG（相対回転グラフ）と、TradingViewベースのRSラインチャートが表示される。
    *   **RSラインチャート (上部)**:
        *   `rs_value` をメインシリーズとして表示。
        *   `rs_value_e14`, `rs_value_e21`, `rs_value_e63` をオーバーレイ表示（デフォルトON）。
        *   市場に対する相対的な強さの時系列推移を可視化。
    *   **RRGチャート (下部)**:
        *   X軸に `RS-Ratio`、Y軸に `RS-Momentum` を取った散布図の軌跡（Trail）を描画。Quadrant（象限）により、Leading(先導), Weakening(弱体化), Lagging(出遅れ), Improving(改善) を視覚化。
    *   **ミニマップ**: RSスコア郡の%Rankの直近30日の時系列推移を左側サイドパネルに表示。

### 3.4 スクリーナーダッシュボード画面 (`/screener` - `ScreenerPage`)
データベースに蓄積された全銘柄に対して、TOMLファイル（`screener_presets.toml`）で定義された独自の検索条件（プリセット）を適用した結果のサマリーを一覧表示する画面。
*   **日付ナビゲーション**: 画面上部で基準日（Base Date）を変更でき、過去の時点でのスクリーナー結果を再現できる。
*   **Rise / Fall タブ**: 買い目線の条件（Rise）と警戒・売り目線の条件（Fall）をタブで切り替え。
*   **プリセットパネル群**: 各条件に該当した銘柄のトップ8件をミニパネルで表示。パネルタイトルをクリックすると、詳細な結果と追加フィルタリングが可能な「スクリーナー結果画面（ScreenerResultPage）」へ遷移。

### 3.5 スクリーナー結果画面 (`/screener/result/:presetId` - `ScreenerResultPage`)
特定のプリセットから遷移、もしくはカスタムでフィルタリングを行うための詳細画面。
*   **カスタムフィルタ（左側サイドバー）**: 各種テクニカル・モメンタムフィルタを動的に設定（APIからメタデータを取得して動的構築）。
    *   **Price & Trend**: 移動平均距離、各種騰落率、Trend Template適合など。
    *   **Volume & Volatility**: ADR%, 出来高急増倍率等。
    *   **Fundamentals**: **時価総額（Market Cap）** の範囲指定。
    *   **Momentum & RS**: RS Rank値の範囲指定。
    *   **Special Conditions (特殊条件)**: RRG象限への突入検知（`RRG Leading In`, `RRG Lagging In`, `RRG Improving In`）。※これらは単なる象限判定だけでなく、中心からの距離（強度）やモメンタムの加速方向を考慮したノイズ除去フィルタが適用されています。
*   **銘柄テーブル（右側メイン表示）**:
    *   条件に合致した全ての銘柄がリアルタイムに表示される。
    *   表の各カラム（1D%, Vol SG, RS21, etc...）をクリックすることでソートが可能。
    *   ティッカー名から該当銘柄の個別チャート画面（ChartPage）へジャンプ。
    *   **★ ウォッチリストボタン**: 各行の左端に★ボタンを配置。クリックでウォッチリストへの追加/解除を即座に行う。entry_date は画面で選択中の基準日が使用される。

### 3.6 ウォッチリスト画面 (`/watchlist` - `WatchlistPage`)
ユーザーが注目銘柄として登録した銘柄のパフォーマンスを一覧管理する専用画面。
*   **タブ切替**: 「Active（登録中）」と「Removed（解除済み）」の2タブ。
*   **Active タブ**:
    *   テーブル列: 指定日 | Ticker | Name | 指定日終値 | 最新終値 | EMA21 | %Gain | Max%Gain | Min%Gain | ADR% | SMA50/ATR% | RS ミニグラフ
    *   指定日はインライン編集可能（日付入力 → PUT API で更新）
    *   ★ボタンで解除（DELETE API）
    *   行クリックで `/chart/{ticker}` へ遷移
    *   デフォルトソート: 登録日（entry_date）降順
*   **Removed タブ**:
    *   「一括クリア」ボタン → 確認ダイアログ → 解除済みレコードを全件物理削除
    *   行クリックで `/chart/{ticker}` へ遷移

### 3.7 全体ポートフォリオダッシュボード画面 (`/portfolio` - `TotalPortfolioPage`)
ユーザーの総資金を俯瞰し、入出金管理やサブポートフォリオへの資金割り当てを行うメインダッシュボード画面。
*   **サマリーパネル**: 総資金、入金総額、現在のP&L、推奨キャッシュ比率（市場フェーズ等に基づき算出）を表示。
*   **円グラフペイン**: 
    *   「キャッシュ vs 株式」の配分グラフ。
    *   「テーマ・セクター別」の配分グラフ（サブポートフォリオ横断での集計）。
    *   「銘柄毎」の配分グラフ（サブポートフォリオ横断での集計）。
*   **トランザクション管理**: 入出金（Deposit / Withdrawal）の実行ボタンと履歴リスト。
*   **サブポートフォリオ・資金配分一覧**: 
    *   各サブポートフォリオのカード（名前、割り当て資金、現在保有銘柄数等）を一覧表示。
    *   各ポートフォリオへの資金配分（Funding）操作機能。
    *   クリックで対象のサブポートフォリオ詳細画面へ遷移。

### 3.8 ポートフォリオ詳細画面 (`/portfolio/:id` - `PortfolioDetailPage`)
特定ポートフォリオのポジション管理、リスク管理、パフォーマンス追跡を行うメイン画面。
*   **サマリーパネル**:
    *   上部に総資金、最大リスク額（1ポジションあたりの最大投資額）、現在の保有ポジション数、投資総額、時価総額、未実現損益（Unrealized P&L）をリアルタイム表示。
*   **4つのタブ切替**:
    1.  **Positions タブ**: 
        *   現在保有中の銘柄一覧。
        *   購入日、購入価格、現在価格、保有株数、損益率・額、損切価格、損切ラインまでの距離（%）を表示。
        *   **アラートバッジ**: 損切ラインに接近（残り3%未満）したポジションがある場合、上部に警告バッジと、該当行の背景色を赤くハイライト表示。
        *   **Buy/Sell フロー**: 「Add Position」で新規購入登録。「Sell」ボタンでインラインフォームを展開し、全株売却または部分売却（Trim）、売却理由（損切/利確等）を選択して実行。
    2.  **History タブ**:
        *   売却済みの取引履歴一覧。
        *   購入日〜売却日、保有日数、売却価格、株数、損益率・額、売却理由を一覧化し、累積 P&L（Cumulative P&L）を追跡表示。
    3.  **Analytics タブ**:
        *   トレードのパフォーマンス統計（勝率、平均利益・損失、Expectancy 等）。
        *   保有銘柄のセクター分散（円グラフ/バーチャット）。
        *   エクイティカーブ（累積損益の推移グラフ、SVG描画）。
        *   月次リターンのヒートマップ風パネル表示。
    4.  **Settings タブ**:
        *   ポートフォリオの基本情報やリスク設定を編集・保存。

### 3.x Universe Manager (`/universe`)

`universe.db` の銘柄定義を編集する画面。トップレベルタブで2つに分かれます。

| タブ | 内容 |
| :--- | :--- |
| **銘柄一覧** | `symbols_master` のインライン編集・テーマ構成の編集・スプレッドシート import/export |
| **IPO候補** | 週次スキャンが検知した新規上場銘柄のレビュー（`UniverseCandidatesPage.tsx`） |

`UniversePage.tsx` は 1,600 行あるため、候補画面は**別ファイルに分離**しています。

#### IPO候補タブ

- **status タブ**: 未レビュー / 自動除外 / 却下済み / 採用済み。それぞれ件数を表示。
  **却下済みもタブから見える**ので永久非表示にはなりません
- **一覧列**: ティッカー / 会社名 / 取引所 / 上場日 / 経過日数 / 時価総額 / 平均出来高 / 株価 / セクタ / フラグ
- **行展開**: 企業概要の全文と、Yahoo Finance / SEC EDGAR / 公式サイトへのリンク。
  テーマのタグ付けを判断するための材料です
- **操作**: 行単位の「追加」「却下」と、チェックボックスによる一括操作。
  追加時にテーマをカンマ区切りで同時指定できます
- **フィルタ**: 上場日の下限 / 時価総額の下限

#### ヘッダのバッジ

未レビュー件数はナビの「Universe」の横に**オレンジのバッジ**として出ます
（`/api/system/health` の `universe.ipo_candidates_pending`）。
ステータス詳細のポップオーバーにも `Universe > IPO Candidates` 行がありますが、
**ポップオーバーはクリックしないと見えず運用されない**ため二重化しています。

### 3.9 バックテスト・シナリオテスト画面 (`/backtest` - `BacktestPage`)
バックテストエンジンの結果確認およびポートフォリオ運用のシナリオシミュレーションを可視化・分析する画面。
*   **タブ切り替え構造**:
*   **📈 ETF Backtest**: 単一のETF商品に対するバックテストレポート。
*   **⚖️ Scenario Test (`RegimeComparisonPage`)**: 複数モデル（レジーム）およびモンテカルロ試行を伴うドリルダウン型統合ダッシュボード。
*   **戦略カードの共通骨格（両タブ共通・`components/BacktestStrategyCard.tsx`）**: タブ間で視線の置き場が変わらないよう、四角枠の構成を固定する。上から **ミニグラフ → 主結果（CAGR / Max DD）→ 2行目 → 3行目 → 末尾（Final Capital + 総ゲイン）**。行の中身だけをタブごとに差し替える。
    *   ETF タブ: 2行目 `Sharpe / Time in Market`、3行目 `Rebalances / Regime Changes`
    *   シナリオタブ: 2行目 `Avg Trade / Win Rate`、3行目 `Trades / Profit Factor`
    *   カードに渡す数値の単位は **% 表記の実数**（0.182 ではなく 18.2）に統一する。シナリオ側 API は率で返すため、呼び出し側で 100 倍して渡す。
    *   ミニグラフのグレー点線は**ベンチマーク**専用。ETF タブは Buy & Hold（SPY 固定にすると TQQQ/SOXL 等でスケール差により線が潰れる）、シナリオタブは SPY。この記法と衝突しないよう、詳細分析チャートの Cash は点線ではなく低 opacity の実線で描く。
*   **実行条件バー（両タブ共通・`components/BacktestRunInfo.tsx`）**: `Period` / `Trading Days` / `Initial Cap` / `Tax Rate` を表示する。毎回参照する値ではないため **デフォルトは折りたたみ**、ヘッダのタップで展開する。値はすべて API 由来（画面へのベタ書き禁止）。シナリオ側は `/api/backtest/scenario/{name}/summary` がこれらを返す（`consider_tax` は `run_params` → 無ければ `backtest_config.toml` フォールバック、`trading_days` は equity CSV の行数）。
*   **シナリオテスト画面の主要レイアウト**:
    *   **モデル選択カード**: `Full Position`, `MTS Raw`, `MTS L1`, `MTS L2`, `MTS L3` の5つのモデル成績を上段に表示し、選択されたモデルのバックテストデータを即座に下段詳細に同期。
    *   **試行ドロップダウン**: モンテカルロ試行に対応する「全統計（all）」および「個別の試行（Run 0 〜 Run 9）」を切り替えるドロップダウン。
    *   **資産曲線チャート**: 折れ線グラフでポートフォリオ評価額、SPY（Lump Sum, DCA, Timing）、QQQ/TQQQ/SOXLベンチマークの累積推移を描画し、下部にCash比率の推移を面グラフで表示。
    *   **年度成績テーブル**: 年度ごとのパフォーマンスとSPYに対する対比成績を表示。
    *   **決済理由分析**: 利確、損切などの決済発生回数、比率、平均損益、平均保有期間をドーナツチャートとテーブルで視覚化。
    *   **取引ログテーブル**: 売買ログを一覧表示。各ヘッダーをクリックして対話的にソート可能（ソート状態はモデルや戦略切り替え時に自動リセット）。
