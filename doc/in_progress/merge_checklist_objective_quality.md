## 2.5 Monte Carlo の CAGR 集計を相乗平均へ（**次のシナリオテスト実行後**に対応）

- [ ] `backend/api/backtest_router.py:442` の `cagr_avg = float(np.mean(cagrs))` が
      **10本の MC run の CAGR を相加平均**している。分散の大きい戦略が有利に見える。
      より実態に近いのは**最終資産の幾何平均**または**中央値**
- [ ] `tmp/` の集計スクリプト群も同じ方法なので、**これまで報告してきた型3 CAGR は
      すべて相加平均**である点に注意（とくに A は run 間の分散が 12.31 と最大で、
      典型値より高く出ている）

> **実施タイミング（ユーザー判断 2026-08-24）**: **次のシナリオテストの後**。
> 先に変えると、今回の結果と過去3世代（`scenario_qual_dd_gen` /
> `scenario_taxopt_cagrobj` / `scenario_tax_preopt`）の比較ができなくなる。
> 変更する場合は**過去世代も同じ方法で再集計**しないと意味がない（保存済みの
> `scenario_summary.json` から再計算できるので、再実行は不要）。

> **設計判断が要る**: 「期待値を見るか、典型値を見るか」の選択でもある。
> 相加平均＝期待 CAGR、幾何平均/中央値＝典型的に得られる CAGR。
> 実運用の判断材料としては後者が適切だが、意図的に決めること。
