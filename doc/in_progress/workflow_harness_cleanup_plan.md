## 2. スコープと設計判断

### 2.1 変更すること

参照記事の原則「ハーネスの各要素は、モデルが何をできないかについての仮定をエンコードしている。
モデル性能の向上に伴い、不要になった部分を段階的に削除する」に従い、
**記述の削除可否を次の基準で判定する**:

| 判定 | 基準 | 例 |
| :--- | :--- | :--- |
| **削除する** | モデルの出力形式・思考手順に関する回避策 | ツール呼び出しの malformed 対策 |
| **残す** | 環境（OS・シェル・文字コード・Git・ファイルシステム）に起因 | CP932 / BOM、`.bat` のマルチバイト、`git worktree remove` のジャンクション追跡 |
| **残す** | このリポジトリ固有のデータ構造・運用の制約 | データ3分類、変更種別 A〜D、プロビジョニング |

**モデルが変わっても環境起因のルールは不要にならない。ここを一緒に削ると事故が戻る。**

### 2.2 変更しないこと（確定した設計判断）

| 論点 | 判断 |
| :--- | :--- |
| ワークツリーを切って作業するか | **切らない**。本項目は worktree の撤収そのものを含み、対象の中で作業すると自分の足元を消す。変更種別も D（設定・ドキュメント）と `tools/` のスクリプト1本のみ |
| `doc/agent_execution_rules.md` の肥大（581行） | **問題としない**。検索前提の資産であり、常時読み込みの CLAUDE.md とは別基準で扱う |
| CLAUDE.md 全体の圧縮 | **やらない**。193行中エージェント行動ルールは40行（21%）で、残りはプロジェクト知識。肥大は発生していないと実測で確認済み |
| skill の正本を `.agents` に戻すか | **戻さない**。`.claude` 側が新しく、孤児プロセスの節（§6）は `.agents` に存在しない。同期方向は `.claude` → `.agents` |

  `check_worktrees.ps1` の棚卸しに組み込んだ。あわせて skill 本文から
  ツール固有の記述（「あなたは Antigravity として」等）を除き、どの AI ツールでも
  読める形に汎用化した。

#### 3-F-2. 転記の完全性チェック（2026-09-07 追加）
